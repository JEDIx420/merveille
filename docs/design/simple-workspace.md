# Simple project workspace amendment

Accepted by the user on 27 November 2026 after reviewing the client-supplied Asana reference document. This supersedes conflicting voice, daily finance and navigation requirements in the earlier next-phase plan. The document's screenshots are workflow references, not instructions to copy real contacts or business records into fixtures.

The daily workspace is Home, Inbox, My Tasks and Projects. Leads and administration remain secondary under Workspace tools. Projects retain Overview, Tasks, Progress, Drawings and Updates; specialist tools and commercial history stay under More. Existing authorized URLs, records, approval rules, email-code access, logo and Dark/Light/System appearance remain.

Tasks use one List/Board/Calendar workspace and one accessible side panel. List is the initial view; a personal server preference remembers the selected view. Private tasks remain owner-only. Board moves request authorized task commands rather than directly writing status. Required completion/block/reopen reasons stay attached to the existing domain actions. Manager assignment/deadline authority and archived read-only state remain. Failed commands keep draft text and reload current data. Quick-add starts with a title; date/assignee are optional proposals until confirmed by the appropriate manager.

Home shows personal work and recent projects instead of financial dashboards. Inbox is a concise unread/all feed with scoped item links. Progress shows non-cancelled project task totals, completion percentage, overdue work and eight weeks of recorded completion events. Recompletion is counted as a new completion event; missing historical events are never invented. Teammate views exclude private tasks and projects outside the viewer's current permissions. Favorites are personal and permission-checked.

Voice controls are removed and the endpoint returns VOICE_DISABLED before parsing audio, reserving quota or invoking AI. Web AI bindings are removed. Dormant model code and quota history remain for traceability; this is not a repaired/re-enabled voice feature. Billing stays external; no cutover or commercial-clearance mutation is performed by this UI change. WhatsApp remains prepared human sharing only, with API delivery disabled.

No portfolios, goals, automation/dependency engine, voice pilot or AI assistant is in this delivery. Motion is short and responsive to actions, honors reduced motion, and reuses the existing permission-aware celebrations. No new animated transactions or historic celebrations are fabricated.

Verification and rollout are recorded in [the implementation evidence](../next-phase/evidence/simple-workspace.md). Team acceptance, company provisioning, Free runtime measurement, backup automation and populated remote recovery remain distinct open gates.
