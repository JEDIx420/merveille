# Expressive studio workspace and bounded automations

Accepted 28 November 2026. Extends the simple workspace amendment; voice stays retired and specialist authority is unchanged.

Design: charcoal #111317 / panel #181B20 / raised #20242B, white on #F7F8FA in Light; Inter 14px body, 22–24px page titles, 4/8/12/16/24/32 spacing. Restrained lavender/sky/teal/coral project identity, initials avatars, contextual edits, grouped task views, saved personal views, connected detail panels. Preserve original logo, semantic statuses, Dark/Light/System, reduced/off motion and private records.

Deliver practical task/checklist templates, controlled labels and personal saved views. Project More and personal settings expose template/manual/generic-AI rule drafting: trigger → conditions → up to three actions → local entity binding → side-effect-free simulation → authorized publication. Staff draft; project managers publish; personal rules stay private. Routine task creation/assignment/date calculation is delegated; drawing approval/release, publication, commercial clearance and client decisions remain human.

Rules execute deterministically without AI using bounded existing 15-minute jobs. Versioned immutable publications, current authority/state checks, atomic idempotent effects, explicit system audit and loop prevention are required. Initial ceilings: 20 active rules/project, 100/org, three actions/rule. AI is optional server-side generic drafting only, no project/person/document context sent; show outbound text. Verify supplied Gemini free project/model/quota before activation. No paid fallback. Provider outage leaves the manual builder and existing rules working.

Keep current staging UAT baseline. Separate preview and local/Workers/browser evidence precede promotion; team acceptance and actual Free CPU/quota measurements remain separate gates.

Prices and provider availability were research observations, not purchased services or guarantees.
