# Stage N03 Evidence — Open-Source Voice Entry & Reviewed Drafts

## Implemented Changes
- **Wrangler AI Binding:** Added `"ai": { "binding": "AI" }` in `wrangler.jsonc` (Free Workers AI tier).
- **Strict Server Audio Validation:** `src/server/voice/wav.ts` (`validateMono16kPcmWav`) validates RIFF/WAVE headers, PCM format (1), mono (1 channel), 16 kHz, 16-bit, declared `data` bytes, and derives duration server-side (<=30s) before quota reservation or inference.
- **Open-Source Model Allowlist & Review-First Pipeline:** `src/server/voice/service.ts` + `POST /api/voice/dictate` (`src/app/api/voice/dictate/route.ts`):
  - Transcription: `@cf/openai/whisper-large-v3-turbo` (MIT).
  - Cleanup/Extraction: `@cf/openai/gpt-oss-20b` (Apache 2.0) with low-effort settings and strict JSON validation (malformed/truncated extraction fails rather than partial writing).
  - Atomic idempotent daily reservation (`QuotaService.reserveAiNeurons`, 8,000 neurons/day & 100 attempts/day ceilings) with conservative settlement and fail-closed exhaustion (zero paid fallback).
  - Deterministic `Asia/Kolkata` relative date resolution (`resolveRelativeDateKolkata`) flagging ambiguous weekdays/times for user confirmation.
  - Raw audio is held only in request memory and never stored in R2 or logged; business records are never auto-saved.
- **UI Component:** `src/components/voice-dictation.tsx` (`VoiceDictationButton`) with browser 16 kHz mono WAV resampling, 30s timer, explicit mic activation, stop/cancel/retry, and review-before-apply UI.
