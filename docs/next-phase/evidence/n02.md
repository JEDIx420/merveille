# Stage N02 Evidence — Simple Leads Tracker & Reviewed Spreadsheet Import

## Implemented Changes
- **Migration:** `migrations/0026_leads_and_imports.sql`:
  - Rebuilt `enquiries` safely so `contact_email` and `site_location` are genuinely nullable (no fake placeholder emails/addresses), added `lead_stage` (`NEW`, `CONTACTED`, `DISCUSSION`, `PROPOSAL`, `WON`, `LOST`, `ON_HOLD`) with conservative backfill from legacy `status`, plus `source_external_id`, `import_batch_id`, `snoozed_until`, and metadata columns.
  - Added `lead_followups`, `lead_activities`, `import_batches`, and `import_batch_rows`.
- **Leads Service:** `src/server/domain/enquiries/leads-service.ts` + `GET/POST /api/leads`:
  - Minimal creation requires only Name + Requirement; `WON` records sales intent without auto-creating projects; `LOST` requires reason; CSV export neutralizes formula injection (`=`, `+`, `-`, `@`, `\t`, `\r`).
  - Clients, representatives, and consultants strictly denied (`FORBIDDEN`).
- **Spreadsheet Parser & Importer:** `src/shared/spreadsheet.ts` (using MIT-licensed `fflate@0.8.3`) + `src/server/domain/enquiries/import-service.ts` + `POST /api/leads/import`:
  - Detects legacy `.xls` binary files with explicit save-as-`.xlsx` instruction.
  - Resolves Excel 1900/1904 date systems, preserves leading-zero/+ phone strings, flags formula cells missing cached values.
  - Bounded 50-row server batches with idempotent retry/resume, Free-tier R2 reservation (falling back to `NO_ORIGINAL_RETENTION` if budget tight), conditional `undoLeadImportBatch` preserving edited/linked leads, and Asana CSV task import into private `personal_tasks` or authorized project `tasks`.
